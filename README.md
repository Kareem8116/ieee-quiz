## رفع على GitHub Pages (مجاني)
1. اعمل GitHub account لو مش عندك
2. اعمل New Repository (اسمه: ieee-quiz)
3. ارفع ملف `index.html`
4. Settings → Pages → Branch: main → Save
5. الرابط هيكون: `https://USERNAME.github.io/ieee-quiz/`
6. رابط الأدمن: `https://USERNAME.github.io/ieee-quiz/?admin=1`

## QR Code
بعد ما تعرف الرابط النهائي، روح على: https://qr.io أو https://www.qrcode-monkey.com
وحط الرابط وحمل الـ QR Code
